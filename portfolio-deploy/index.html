🎨 Neural Style Transfer

An AI-powered image generation application that combines the artistic style of one image with the visual content of another using Deep Learning and Convolutional Neural Networks (CNNs).

📖 Overview

Neural Style Transfer is a Deep Learning application that creates artistic images by transferring the visual style of one image onto the content of another. The system extracts high-level content features and artistic style features using a pre-trained VGG19 Convolutional Neural Network and generates a completely new image through iterative optimization.

🎯 Problem Statement

Creating artwork manually requires significant artistic skills and time. This project automates the process by allowing users to upload a content image and a style image, then generates a new image that preserves the content while adopting the artistic style.

✨ Key Features

  • Upload Content Image
  • Upload Style Image
  • AI-Based Style Transfer
  • Deep Learning Image Generation
  • Real-Time Progress Display
  • High-Resolution Output Image
  • Responsive Web Interface
  • Download Generated Artwork
  • Fast Image Processing
  • User-Friendly Interface

🛠 Tech Stack

Python PyTorch TorchVision VGG19 OpenCV PIL NumPy Flask HTML5 CSS3 JavaScript GitHub

⚙ Workflow

  1. Upload a Content Image
  2. Upload a Style Image
  3. Preprocess Both Images
  4. Extract Content Features using VGG19
  5. Extract Style Features using Gram Matrices
  6. Optimize the Generated Image
  7. Combine Content and Style Loss
  8. Generate the Final Stylized Image
  9. Download the Generated Artwork

🧠 Deep Learning Model

  • Pre-trained VGG19 CNN
  • Feature Extraction Layers
  • Gram Matrix for Style Representation
  • Content Loss Optimization
  • Style Loss Optimization
  • Weighted Total Loss Function

🚀 Challenges Solved

  • Balanced style and content preservation.
  • Optimized image generation speed.
  • Maintained high-quality output resolution.
  • Integrated Deep Learning model with a web interface.

🔮 Future Improvements

  • Multiple Style Blending
  • Video Style Transfer
  • Live Camera Style Transfer
  • Anime & Cartoon Style Models
  • GPU Acceleration
  • Batch Image Processing

🏥 Anganwadi Management System

A desktop-based management system developed to digitize Anganwadi center operations by managing beneficiary records, nutritional information, and report generation through a centralized MySQL database.

📖 Overview

The Anganwadi Management System is a desktop application developed to simplify the daily operations of Anganwadi centers. It replaces manual record keeping with a digital solution for managing beneficiaries, attendance, nutritional records, and reporting. The application provides an efficient and organized way to store, retrieve, and update data while reducing paperwork and improving data accuracy.

🎯 Problem Statement

Traditional Anganwadi centers rely heavily on paper-based records, making data management slow, error-prone, and difficult to maintain. This project digitizes the entire workflow by providing a centralized system for beneficiary management, attendance tracking, and report generation.

✨ Key Features
